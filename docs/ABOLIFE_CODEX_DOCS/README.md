# AboLife Codex Docs

Diese ZIP enthält die Markdown-Dokumente, die als Grundlage für Codex dienen sollen.

Empfohlene Nutzung:

1. ZIP entpacken.
2. Den Ordner `docs/` in dein AboLife-Projekt kopieren.
3. Erst danach Codex starten.
4. Codex immer zuerst diese Dokumente lesen lassen.

Enthalten:

- `docs/PRODUCT_SPEC.md`
- `docs/MVP_SCOPE.md`
- `docs/ARCHITECTURE.md`
- `docs/DATA_MODEL.md`
- `docs/UI_SPEC.md`
- `docs/ROADMAP.md`
- `docs/CODEX_RULES.md`

Wichtig:

AboLife v1 soll lokal, fokussiert und dashboard-first bleiben. Telegram, iPhone, KI, Health und Web sind spätere Erweiterungen.
