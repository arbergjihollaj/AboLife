# Sicherheit und persönliche Daten

Bitte keine Zugangsdaten, Sitzungskennungen, Datenbankdateien, Backups oder persönlichen Kalender-/Gesundheits-/Finanzdaten in Issues oder Pull Requests veröffentlichen.

Sicherheitsprobleme können über GitHubs private Meldemöglichkeit gemeldet werden, sofern diese für das Repository aktiviert ist. Ist sie nicht verfügbar, zunächst ein Issue ohne technische Ausnutzungsdetails oder persönliche Daten eröffnen und um einen privaten Kontaktweg bitten.

Die Weboberfläche ist für die persönliche Nutzung auf einem privaten Homelab ausgelegt. Produktive Daten benötigen eine eigene HTTPS-Adresse, ein eigenes starkes Passwort und geeignete Netz-/Backupregeln. Zugangsdaten werden weder mitgeliefert noch für einen öffentlichen Demoserver verwendet.

Der optionale Demomodus verwendet ausschließlich fiktive Daten in einer temporären Datenbank. Er lädt keine persönliche Datenbank und übernimmt keine bestehenden Sicherungen.

Ein lokaler Quelltext-Scan ersetzt keine Sicherheitsprüfung und ist keine Aussage über unbekannte Schwachstellen. Prüfstand und Grenzen stehen in [TESTING.md](TESTING.md).
